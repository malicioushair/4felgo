UniqueCircularBuffer Class

template <typename T, typename ID, size_t CAPACITY, typename KeyOfFn> class UniqueCircularBuffer

Fixed-capacity FIFO buffer that rejects duplicate entries by key. More...

Header: #include <UniqueCircularBuffer>

Detailed Description

When full, the oldest entry is evicted on push. Duplicate keys are ignored.

Felgo's QDoc 6.8 does not create member nodes for this inline class template, so its public API is recorded here:
