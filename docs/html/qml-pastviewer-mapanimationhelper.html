MapAnimationHelper QML Type

Smooth map center and zoom animations with cluster-split detection. More...

Import Statement: import PastViewer

Detailed Description

Provides animated transitions when the user selects a photo from the carousel or taps a clustered marker. After animation completes, triggers a viewport update on pastVuModelController.

Property Documentation

map : var [required]

The Map instance to animate. This property is required.


running : bool [read-only]

Read-only; true while a center or zoom animation is in progress.


Method Documentation

void animateMapCenter(targetCoordinate)

Animates the map center to targetCoordinate without changing zoom.


void animateMapCenterAndZoom(targetCoordinate, targetZoom, clusterCoordinate)

Animates center to targetCoordinate, zoom to targetZoom; clusterCoordinate is used for viewport refresh.


void animateMapZoom(targetZoom, clusterCoordinate)

Animates zoom to targetZoom; clusterCoordinate is used for viewport refresh.
