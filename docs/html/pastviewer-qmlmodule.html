PastViewer QML Types

BasePage

Base page with themed background and Android back-key handling

CameraMode

Camera overlay that aligns a historical photo with the live viewfinder

ClusterMarker

Circular map marker showing the number of photos in a cluster

Compass

North-up compass dial that snaps the map bearing to zero on tap

ErrorMessageDialog

Fatal error dialog that quits the application on dismissal

Footer

Bottom toolbar displaying contextual page information

Header

Navigation header with back button and page title

Main

Felgo application root with QML hot-reload support

MainWindow

Root visual container with navigation stack and error handling

MapAnimationHelper

Smooth map center and zoom animations with cluster-split detection

MapPage

Primary map screen with markers, controls, and onboarding

OnboardingOverlay

Step-by-step tutorial overlay with optional UI element highlighting

PhotoDetails

Full-screen photo viewer with pinch-to-zoom and share action

PhotosNear

Horizontal carousel of historical photos near the user's location

PovDirection

Map marker with a directional arrow indicating photo point of view

RecenterButton

Button that recenters the map on the user's current location

RectangleWithHoles

Dimmed overlay with transparent rectangular cutouts

SettingHelpHint

"?" button that opens a popup with a setting description

SettingWithHint

Layout row that places a setting control next to an optional help hint

Settings

Application settings: language, timeline filter, and display options

SettingsButton

Hamburger-menu icon button that opens settings

StyledButton

Themed push button with accent background and rounded corners

StyledCheckBox

Themed checkbox with rounded indicator and accent fill

StyledRangeSlider

Dual-handle range slider for selecting a year timeline

StyledSliderHandle

Circular drag handle for StyledRangeSlider

UserPosition

Device location indicator shown on the map
