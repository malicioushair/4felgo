RectangleWithHoles QML Type

Dimmed overlay with transparent rectangular cutouts. More...

Import Statement: import PastViewer
  • List of all members, including inherited members
  • RectangleWithHoles is part of PastViewer Helpers.

Properties

  • highlightBorderColor : color
  • highlightBorderWidth : int
  • holeRadius : int
  • holes : var
  • overlayColor : color

Detailed Description

Renders framing rectangles around the first hole for a spotlight effect and uses the C++ PastViewer::HoleItem type to forward pointer events.

Property Documentation

highlightBorderColor : color

Color of each highlighted hole border.


highlightBorderWidth : int

Width of each highlighted hole border.


holeRadius : int

Corner radius used for highlighted holes.


holes : var

Rectangles that remain transparent and accept pointer events.


overlayColor : color

Color of the dimmed area around the holes.
