PastViewer GUI Items

ClusterMarker

Circular map marker showing the number of photos in a cluster

Compass

North-up compass dial that snaps the map bearing to zero on tap

PhotosNear

Horizontal carousel of historical photos near the user's location

PovDirection

Map marker with a directional arrow indicating photo point of view

RecenterButton

Button that recenters the map on the user's current location

SettingHelpHint

"?" button that opens a popup with a setting description

SettingWithHint

Layout row that places a setting control next to an optional help hint

SettingsButton

Hamburger-menu icon button that opens settings

StyledButton

Themed push button with accent background and rounded corners

StyledCheckBox

Themed checkbox with rounded indicator and accent fill

StyledRangeSlider

Dual-handle range slider for selecting a year timeline

StyledSliderHandle

Circular drag handle for StyledRangeSlider

UserPosition

Device location indicator shown on the map
